# FoodWise

FoodWise is a food-waste prevention and surplus redistribution platform.

## Project goals
- Help food providers prevent food waste.
- Support redistribution of surplus food from hostels,canteens and caterers.
- Connect food providers with NGOs.
- Provide food-waste insights.

## Technology
- Frontend: React
- Backend: Node.js and Express
- Database: MongoDB
